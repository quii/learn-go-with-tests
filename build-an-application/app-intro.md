# はじめに

_Go言語：基礎_ のセクションをしっかり消化できていれば、Goの言語機能の大部分とTDDのやり方について、確かな基礎が身についているはずです。

次のセクションでは、アプリケーションを構築します。

各章は前の章を土台に繰り返し改良を重ね、プロダクトオーナーの指示に従ってアプリケーションの機能を拡張していきます。

優れたコードを書きやすくするための新しい概念が紹介されますが、新しく学ぶ内容のほとんどは、Goの標準ライブラリで何が実現できるかということです。

この学習が終わる頃には、テストに裏打ちされたGoのアプリケーションを反復的に書く方法をしっかりと理解しているはずです。

* [HTTPサーバー](http-server.md) - HTTP リクエストを受信し、それに応答するアプリケーションを作成します。
* [JSON、ルーティング、埋め込み](json.md) - エンドポイントがJSONを返すようにし、ルーティングの方法を調べます。
* [IO、並び替え](io.md) - データをディスクに永続化して読み込み、データのソートについても扱います。
* [コマンドライン、プロジェクト構造](command-line.md) - 1つのコードベースから複数のアプリケーションをサポートし、コマンドラインからの入力を読み込みます。
* [時間](time.md) - `time` パッケージを使ってアクティビティをスケジュールします。
* [WebSocket](websockets.md) - WebSocketを使用するサーバーの書き方とテスト方法を学びます。
